# UrbanFlow Dublin

# Dublin's UrbanFlow

An public transportation analytics system called UrbanFlow Dublin looks into Dublin's weather-related commuter behavior, Dublin Bike usage trends, and the dependability of public transportation.

By providing mobility insights through interactive visualizations and data analysis, the project seeks to assist commuters, students, and city planners.
## Project Objectives

- Analyse Dublin Bikes usage patterns using recent open datasets.
- Explore peak-hour mobility trends in Dublin.
- Investigate how weather conditions may influence cycling and commuting behaviour.
- Store collected data in a database for further analysis.
- Develop an interactive web-based system for visualising urban mobility insights.

## Technologies Planned

- React for frontend development
- Python Flask for backend API development
- PostgreSQL for database storage
- Plotly/Chart.js for data visualisation
- Leaflet for map-based visualisation
- GitHub for version control
- Trello for agile project management
- Postman, Jest and Cypress for testing

## Data Sources

- Dublin Bikes historical open data
- GTFS public transport route/stop data
- Met Éireann weather data/API
- Stored project database snapshots

## Project Phases

### Phase 1: Planning and Learning
Requirements gathering, dataset research, GitHub setup, Trello setup, and system design.

### Phase 2: Implementation
Backend development, database setup, dataset cleaning, API integration, frontend development, and analytics features.

### Phase 3: Testing and Deployment
Testing, debugging, deployment, documentation, and final report preparation.
